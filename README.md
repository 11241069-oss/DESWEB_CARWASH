
# 🚗 Website Informasi dan Reservasi Layanan Car Wash

Repositori ini dibuat untuk memenuhi **Tugas Akhir Mata Kuliah Desain Web (Desweb)** sekaligus sebagai **Portofolio Magang**.

Proyek ini merupakan sebuah *Website Informasi dan Reservasi Layanan Car Wash* berbasis web. Website ini dirancang untuk memudahkan pelanggan dalam mencari informasi layanan cuci mobil dan melakukan reservasi secara online, serta dilengkapi dengan *Dashboard* Admin untuk mengelola data pesanan.

## ✨ Fitur Utama

**👤 Sisi Pelanggan (Customer):**
- Melihat katalog informasi layanan Car Wash (harga, deskripsi, durasi).
- Melakukan reservasi (input nama, no HP, tanggal, dan jam).
- Mendapatkan **Kode Booking** unik secara otomatis.
- Melacak status reservasi secara *real-time* menggunakan Kode Booking.
- *(Tambahkan fitur lain jika ada, misal: Melihat lokasi via Maps / Hubungi via WA)*

**👨‍💼 Sisi Admin (Dashboard):**
- Login khusus Admin (dilengkapi enkripsi password).
- Melihat daftar semua reservasi yang masuk.
- Mengelola data reservasi (mengubah status: Pending -> Dikonfirmasi -> Selesai).

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman:** PHP (Native)
- **Database:** MySQL
- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Server Lokal:** XAMPP
